This page has an absolutely positioned element that sits outside the normal document body, marked with a red border below. Because it is out of flow, the height of the body does not include it.

iframe-resizer's auto mode finds it anyway. The child watches for elements that overflow the body, marks them with data-iframe-overflowed, and sizes the frame to cover them, so this page needs no configuration.

a a a

To size the frame from a single element instead, put data-iframe-resize on it. To have an overflowing element left out of the calculation, put data-iframe-ignore on it, as the overflow example shows.
